# VidzyAI

An AI-powered YouTube video understanding tool (work in progress).

## Overview
VidzyAI fetches YouTube video transcripts and uses LLMs (via LangChain and Google Gemini)
to answer questions, summarize content, and extract insights from videos.
Transcript embeddings are stored in FAISS for efficient semantic retrieval (RAG).

## Tech Stack
- Python, LangChain, Google Generative AI
